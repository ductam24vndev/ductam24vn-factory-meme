## 1. HƯỚNG DẪN CÀI ĐẶT TRÊN WINDOWS (Windows 10 / 11)

1. Tải file nén Windows theo đường dẫn ở trên.
2. Nhấp chuột phải vào file DUCTAM24VN_FACTORY_MEME_Windows_v1.0.zip -> Chọn **Extract All...** (Giải nén toàn bộ).
3. Mở thư mục vừa giải nén, tìm file: DUCTAM24VN_FACTORY_MEME_Win.exe.
4. Nhấp đúp chuột để khởi chạy.
   - *Xử lý bảo mật Windows SmartScreen:* Nếu xuất hiện bảng thông báo xanh *"Windows protected your PC"*, bấm vào dòng chữ **More info** (Thông tin khác) -> Chọn nút **Run anyway** (Vẫn chạy).
5. *(Mẹo)* Chuột phải vào file .exe -> Chọn **Show more options** -> **Send to** -> **Desktop (create shortcut)** để tạo lối tắt ra ngoài màn hình chính.

## 2. HƯỚNG DẪN CÀI ĐẶT TRÊN macOS (MacBook / iMac / Mac mini)

Cơ chế bảo mật Gatekeeper trên macOS sẽ mặc định khóa các phần mềm bên ngoài App Store. Bạn xử lý theo các bước sau:

1. Tải file nén macOS theo đường dẫn ở trên và nhấp đúp để giải nén.
2. Kéo file DUCTAM24VN_FACTORY_MEME_Mac.app thả vào thư mục **Applications** (Ứng dụng).
3. **Mở lần đầu tiên:**
   - Không nhấp đúp trực tiếp.
   - Giữ phím **Control** (hoặc bấm chuột phải) vào ứng dụng -> Chọn **Open** (Mở).
   - Hộp thoại cảnh báo xuất hiện -> Bấm nút **Open** xác nhận một lần duy nhất.
4. *Nếu máy Mac báo "Ứng dụng bị hỏng / App is damaged" hoặc "Không thể mở":*
   - Mở **Terminal** (nhấn tổ hợp Cmd + Space, gõ Terminal rồi Enter).
   - Dán lệnh sau và nhấn Enter:
     `ash
     xattr -cr /Applications/DUCTAM24VN_FACTORY_MEME_Mac.app
     `
   - Nhập mật khẩu máy Mac (nếu có yêu cầu) rồi bấm Enter. Sau đó mở lại ứng dụng bình thường.

## 3. TÍNH NĂNG CHÍNH & PHÍM TẮT THAO TÁC NHANH

- **Tìm kiếm thông minh:** Gõ tên sound meme bất kỳ (tiếng Việt hoặc tiếng Anh) và nhấn Enter để tìm nhanh.
- **Phím SPACE (Dấu cách):** Tạm dừng / Tiếp tục phát âm thanh đang chọn.
- **Phím MŨI TÊN LÊN / XUỐNG:** Duyệt nhanh qua từng âm thanh và tự động nghe thử kèm biểu đồ sóng âm.
- **Kéo thả vào CapCut:** Bấm giữ chuột trái vào tên sound và kéo thẳng sang timeline hoặc khung "Tệp phương tiện" của CapCut Desktop.
- **Nút "+ Add":** Nạp các thư mục chứa sound có sẵn trên máy vào thư viện để quản lý tập trung.
- **Nút Download:** Lưu trữ các âm thanh online yêu thích về ổ cứng vĩnh viễn.
